Vos questions

Les bons repères,
avant votre visite.

Comment demander un rendez-vous ?

Choisissez une date souhaitée dans le calendrier, puis préparez votre message WhatsApp. Le cabinet confirme directement le rendez-vous.

Dois-je créer un compte ?

Non. Vous pouvez appeler, écrire sur WhatsApp et préparer une demande sans inscription.

Où se trouve le cabinet ?

Au 48 avenue Habib Bourguiba, au 2ᵉ étage, cabinet n°2.2, Ariana. Le bouton Google Maps ouvre la fiche de l’établissement.

Mes coordonnées sont-elles enregistrées ?

Le site prépare votre message dans votre navigateur sans enregistrer vos coordonnées. Le message est envoyé uniquement lorsque vous confirmez dans WhatsApp.

La carte est chargée depuis Google Maps uniquement lorsque vous l’ouvrez.
